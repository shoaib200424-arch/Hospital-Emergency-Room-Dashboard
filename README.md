# 🏥 Hospital Emergency Room Dashboard

An interactive **Hospital Emergency Room Analytics Dashboard** built using **Microsoft Excel** to analyze patient volume, waiting time, satisfaction, admission status, demographics, and department referrals.

## 📊 Project Overview

Emergency departments generate a large amount of patient data every day. This dashboard converts raw hospital data into meaningful insights that can help management understand patient flow and overall emergency-room performance.

## 🎯 Business Problem

The hospital management wants to answer important questions such as:

* How many patients are visiting the emergency room?
* What is the average patient waiting time?
* How satisfied are patients with the service?
* How many patients are admitted?
* Which age groups have the highest patient volume?
* Which departments receive the most referrals?
* How does patient volume change over time?
* How many patients were attended within the required time?

## 📌 Key KPIs

* **Total Number of Patients**
* **Average Wait Time**
* **Average Patient Satisfaction Score**
* **Admitted Patients**
* **Patients Attended Within Time**

## 📈 Dashboard Analysis

The dashboard includes:

* Patient volume by age group
* Patient count by gender
* Admission status analysis
* Department referral analysis
* Patient attendance within time
* Daily patient volume trend
* Daily average waiting-time trend
* Daily satisfaction-score trend
* Monthly and yearly analysis
* Interactive filters and slicers
